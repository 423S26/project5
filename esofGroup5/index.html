Dashboard Home

Purpose

The Survey Analytics Dashboard helps the Empowerment Center analyze alumni exit survey data from Qualtrics exports. The tool generates visualizations and statistics that can be used in funding proposals and presentations, eliminating the need for manual data analysis in Excel.

Instructions

In the "Responses" page, select a data file to upload. Make sure the file is in a CVS format (Comma Seperated Value).

Once the file has been loaded (Indicated by the "CVS Loaded" text), go to the "Analytics" page. Questions can be selected in the dropdown prompt

The program will then automatically detect the question type (i.e. multi-select, Likert scale, Ranking, Short Answer, and Yes or No). If the program detects the question type incorrectly, it can be manually selected using the "Question Type" input.

Once the question type is determined, a graph will be generated from the answers.
