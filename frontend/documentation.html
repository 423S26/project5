User Documentation

Analytics Dashboard for the Empower Student Center

A web application that transforms Qualtrics survey CSV exports into interactive visualizations and statistics - reducing hours of manual Excel work to minutes.

How To Use

Step 1: Export from Qualtrics

  1. Log into Qualtrics
  2. Open your survey and go to the Data & Analysis tab
  3. Click Export & Import, then Export Data
  4. Select CSV format and download the file

Step 2: Upload your CSV

On the Upload page, click Choose File, select your exported CSV, then click Upload File. If you just want to explore the app, click Use Example File to load the built-in coffee shop survey instead.

Step 3: Analyze questions

Go to the Analytics page. All survey questions will appear as clickable cards. Use the search bar or type filter to narrow them down.

Step 4: View statistics and charts

Click any question card to see a response preview and auto-detected question type. If the type is wrong, use the Question Type dropdown to correct it and click Save Type. The statistics and chart will update automatically. Click Download Graph to save the chart as a PNG.

Developer Documentation

Running Locally

Requirements

  • Python 3.9+
  • A modern web browser (Chrome, Firefox, Safari, Edge)

1. Set up the virtual environment

python -m venv .venv
source .venv/bin/activate    # macOS/Linux
# .venv\Scripts\activate     # Windows
pip install -r requirements.txt

2. Start the Flask backend

python backend/main.py

The server will start on http://localhost:5001.

macOS note: Port 5000 is reserved by AirPlay Receiver, so we use 5001. If you see a 403 error, make sure you're hitting port 5001, not 5000.

3. Open the app

Navigate to http://localhost:5001 in your browser. Do not open the HTML files directly - they need to be served through Flask for uploads to work.

Running Tests

pytest backend/test_main.py -v

36 tests covering upload parsing, auto-detection, and all API endpoints.
