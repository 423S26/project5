Dashboard Home

Purpose

The Survey Analytics Dashboard helps the Empowerment Center analyze alumni exit survey data from Qualtrics exports. The tool generates visualizations and statistics that can be used in funding proposals and presentations, eliminating the need for manual data analysis in Excel.

Instructions

In the "Responses" page, select a data file to upload. Make sure the file is in a CVS format (Comma Seperated Value). Once the file has been loaded (Indicated by the "CVS Loaded" text), go to the "Analytics" page for further analysis of a specific question.

To select a specific question for analysis, click on the box containing said question. You can also filter questions using the search bar or by using the dropdown menu to select a specific type of question (i.e. Multiple Choice, Likert Scale, Ranking, Short Answer, Yes or No)

Once a question has been selected, the page will scroll down to the analytics of that specifc question. It will have a preview of the top 5 responses, and a manual Question Type Selector, in case the algorithm was wrong about the question type. To change the type, use the dropdown menu to select a new type, and click on the "Save Type" Button.

In the "Statistics" section, the application will give the number of counted responses, as well as a mean, median, mode, and standard deviation, if they are applicable to the question type. The application will also generate a graph (if applicable) based on the recorded responses. To download the graph, click on the "Download Graph" button, just below the graph.
